# 三分钟演示脚本

演示目的：让评委看到同题视角差异、可追溯的 AI 资料三问，以及重新发起真人讨论的完整路径。视频只展示实际运行结果，不用预录答案冒充实时模型。

| 时间 | 操作 | 讲解要点 |
|---|---|---|
| 0:00–0:20 | 打开首页过来人频道 | 同一问题，在不同生活阶段可能得到不同理解。独立网页，手机电脑共用一套体验。 |
| 0:20–0:50 | 打开“不快乐”示例，切换小学与工作阶段 | 问题保持不变，看到关心点差异。说明这组跨阶段回答是设计示例，不宣称已有真实用户规模。 |
| 0:50–1:05 | 返回原位置，打开“工作后交朋友” | 阅读、阶段筛选、点赞和返回是完整的真人问答路径。 |
| 1:05–1:35 | 展开资料区，发送“在陌生城市工作，怎样交到志同道合的朋友？” | 官方知乎搜索摘要进入本地库；AI 引用资料回答，不假扮任何阶段的人。展示来源标题、短引和摘要范围。 |
| 1:35–2:05 | 发送第二、第三问，展示次数变化 | 追问围绕同一证据范围；建议问题只填入，用户明确发送。第三问后停止，不延展为无限聊天。 |
| 2:05–2:35 | 选择自己的一条追问，点“带着这个问题问大家”，编辑并选择阶段 | AI 帮助澄清问题，真人提供亲身经历。必须确认发布，不自动把 AI 结论变成用户观点。 |
| 2:35–3:00 | 返回/展示资料来源与技术说明 | 核心价值是跨阶段理解与连接；Python、SQLite、外部模型，失败不妨碍普通问答。说明仍待真实用户验证的部分。 |

联调追问候选：

1. 在陌生城市工作，怎样交到志同道合的朋友？
2. 根据这些资料，和同事发展友谊有哪些需要注意的边界？
3. 如果不想只认识同事，资料里还提到了哪些认识朋友的途径？

演示前使用独立测试访客完成准备，不清空线上真实用户数据。若模型繁忙或失败，展示真实提示与来源；不能将失败剪成成功。最终视频链接和验证日期在交付检查中登记。
