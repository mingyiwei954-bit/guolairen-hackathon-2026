# 第三、第四层导航：顶部优先的滚动规则

- 页面向下走：360ms渐隐。
- 中途第一次向上回看不触发展开；连续第二次回看触发360ms完整渐显，不设置距离门槛，也不等待手势结束。中途反向移动清零。
- 每次touchstart区分手机手势；桌面wheel按240ms静默间隔分组，同次惯性事件不重复计数。
- 到达scrollTop<=1（含触摸顶部负向回弹）立即完整显示，取消任何尚未结束的隐藏动画。单击栏目、双击刷新、进入频道均显示。
- 顶部始终保留导航的自然文档空间，随正文正常滚出视野。动画不再改变占位高度、不修改scrollTop，也不向上平移导航。
- 第二次回滑触发后，渐显按时间自行完成；后续同方向输入不反复重启动画。离开页面清理动画和监听。

本地浏览器用键盘驱动真实页面滚动：6轮中途连续两次回看；6轮隐藏后直接Home到顶，逐轮测得scrollTop=0、opacity=1、首条内容偏移49px与导航高度相同。单元测试覆盖30轮无滚动位置修改、极小手势、惯性、方向变化、顶部负向回弹、动画中途到顶、显式栏目展开和离页清理。触摸手势部分为模拟输入测试，并非手机真机手感验收。

运行：`node tests/test_filter_gestures.cjs`。
