# 第三、第四层导航稳定性修复

进入频道或重新打开页面时，保留浏览方向、阶段与阅读位置，筛选导航强制完整显示；详情返回仍可恢复原来的收起状态。历史半透明值恢复为完整显示。单击当前过来人频道也能显式展开，双击刷新保持原流程。

隐藏时把占位高度设为0；显示时恢复导航实际高度。中途切换高度补偿scrollTop，并禁用浏览器自动滚动锚定，避免补偿两次。布局调整不记为手势。

一次完整回滑计数一次，第二次连续回滑显示。慢速移动累计距离，不再丢弃所有小于1.75px的输入帧；方向未确认的微抖动不能把同次手势计为两次。取消触摸、切换页面会结束或清理延迟动画。页面恢复的异步绑定须核对原节点仍有效。

验证：`node tests/test_filter_gestures.cjs` 覆盖20轮隐藏/显示无位置漂移、占位归零、慢速触摸、微抖动、惯性、方向清零、边界、键盘重复与离页清理。另完成本地浏览器键盘驱动的6轮真实页面上下滚动、4轮频道来回切换及单击频道恢复。触摸输入使用模拟事件回归，真机触感未冒充已验证。
