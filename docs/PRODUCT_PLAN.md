过来人，听听另一程。
参赛主题：灵魂匹配局——社区连接与兴趣社交

你的困惑，也许有人走过。你的经历，也许有人正需要。

一、创作思路：让一个问题，成为人与人相遇的开始
工作第二年的年轻人，可能需要一个孩子简单的视角；即将毕业的学生，可能想听听工作多年的人怎么选择；一个子女，也可以替即将退休的父母问问另一种生活。
我们提出的产品假设是：除了深入、专业的知识交流，知友也需要一种更轻盈的方式，诉说近况、提出生活里的小疑问，并听见自己所处阶段之外的声音。
过来人围绕“共同的问题＋不同的人生阶段”组织交流。求学、工作、退休是帮助视角相遇的入口，不是经验高低的排名。每个人都可以提问，也都有一程经历值得分享。

二、核心优势：双向、轻盈、有回应
【双向理解】
“听过来人说”，让用户了解尚未走到的人生阶段；“听没过来人说”，让成年人重新看见简单、直接的生活视角。孩子可以带来启发，前辈也可以坦诚困惑。我们希望交流有来有往，让不同阶段的人互相理解。
【轻盈表达】
一句近况、一个小问题、一两句回答，就能开始交流。公开昵称与头像建立联系，人生阶段提供语境。连续阅读、轻符号分隔、柔和转场，以及点赞、收藏、追评，让用户以很小的动作表达“我听见了”，降低开口与继续讨论的负担。
【主动选择】
用户可以选择想听哪个阶段的声音，也可以替朋友、家人提问。问题标签、话题与图文回答让表达更具体，避免把跨阶段交流变成泛泛的劝导。

三、适配知乎社区的场景价值
知乎积累了丰富的知识与生活经验。过来人希望给这些经验增加一个自然的相遇入口：从“我关心的一个问题”出发，发现不同阶段的人，再通过一次回答、一条追评继续交流。
它与“灵魂匹配局”的契合点，在于围绕共同关切连接知友：观点在回答中显现，理解在追评中发生，关系从轻量互动中开始。我们希望用户既获得新的视角，也发现自己的普通经历可以帮助别人。
典型场景包括校园与职场转换、生活情绪、朋友关系、家庭代际理解和退休生活想象。阶段由用户自述，不从外部内容推测真实作者的年龄。

四、产品体验：从诉说，到回应，再到理解
用户进入“过来人”频道，选择浏览方向和人生阶段；在同一个问题下连续阅读不同经历，点赞、收藏或展开追评。
用户也可以发布自己的问题，或用文字、图片、话题和标签写下回答；支持草稿与图片查看，提交后持久化到本项目。
听完大家的经历，如果还想多理解一点，可以“问问看山”。看山以简短、克制的表达整理思路，并给出可继续阅读的来源线索。思考动画与轻微文字淡入让等待有反馈，回答出现后保持阅读位置。

五、技术方案：让 AI 支持交流与理解
采用原生 Web 前端、Python 服务、SQLite、HTTPX 与 DeepSeek，一套页面适配手机和电脑展示。
独立 Answer Agent 负责资料检索、证据组织、生成与引用校验。结合本地来源库和知乎官方搜索，保留原始链接，区分摘要与全文；模型不能编造来源链接。活动故事素材单独标记并排除在事实证据检索之外。
话题检索接入知乎官方内容搜索，展示相关内容；本项目问答在自己的数据库发布，不宣称拥有知乎站内发帖接口。项目已接入知乎 OAuth 登录。
请求去重、并发控制、持久化状态与失败提示保障主流程；图片验证后保存，源码、密钥和数据分开管理，部署保留数据备份与版本回退。

六、完成度与演示边界
在线 Demo 已具备双向阶段浏览、图文提问与回答、点赞收藏、追评、消息、看山回答与来源查看等体验。76 项后端测试通过，已检查核心浏览、发布、互动与 AI 链路。
为呈现完整社区过程，演示站提供近百个问题的 mock 场景、热度梯度和热门追评；发布后可触发模拟赞同与简短 AI 角色回应。角色带有设定年龄和表达约束，并明确标识为 AI 角色。模拟数据不代表真实用户规模，不向知乎社区自动发帖。
目前尚无规模负载、全机型触摸和真实留存结论。下一步邀请不同阶段的体验者同题作答，验证是否获得新视角、是否愿意继续讨论，以及是否感受到自己的经历有价值。

过来人想留下的，是一次轻轻的回应：
