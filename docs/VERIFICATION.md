# 交付检查

核验日期：2026 年 9 月 14 日（北京时间）。本地实现已完成，公网发布及正式提交正在收尾。

## 本地实现与验证

- 后端全量隔离测试 **28/28 通过**，其中三问专项 11 项：计数、幂等、并发、访客隔离、固定证据、首次/后续资料不足、来源撤回与中断恢复。原资料查询、单轮 AI、浏览、提问、回答、点赞回归通过。
- JavaScript 语法检查与 Git diff 空白检查通过。
- 真实模型：隔离 API 一轮三问和浏览器一轮三问均完成，共 6 个成功回答；每次均有原文短引、真实来源链接和 summary 范围。重复请求不增加次数，刷新恢复，第四问被服务端拒绝。
- 浏览器：第三条 item 进入详情、同题阶段切换、点赞、提交回答后定位本人阶段、新回答、返回原问题锚点和焦点；全过程通过。
- 三问：点击建议只填入；第三问发送后立即刷新，重进恢复三条记录；三问结束关闭发送；选追问转真人表单、取消恢复、编辑及显式发布均通过。测试发言只进入隔离库。
- 390／430 CSS 像素 iframe 与桌面手机容器检查通过。固定标签列、两行问题／四行代表回答、空回答状态均可用。筛选完全隐藏时高度为零、inert、aria-hidden=true，不接受点击或焦点；反向滚动能展开。
- 初始跨阶段回答标注「示例」；访客新回答标注阶段自述；AI 区标注「AI 依据资料整理」。

## 数据与边界

- 八个初始问题、十一条回答及初始赞数为示例。两条知乎资料是官方搜索返回的真实摘要，不是全文，作者年龄与阶段未知。
- 实际模型测试与模拟测试分开记录。超时、401、余额不足、429、空响应、错误 JSON、非法引用等失败分支使用模拟响应；不声称真实制造过每类上游故障。
- 尚无真实 iPhone 键盘设备验收、规模负载测试、用户留存或增长数据；390／430 的检查是浏览器 CSS 视口验证。
- Cookie 标识访客而非自然人；清除 Cookie 会产生新访客。当前不含 OAuth、真人私信、付费、自动重开或无限 Agent 循环。
- 资料覆盖很小，检索使用中文二元词片与英文单词匹配；不匹配或资料不足会明确停止，不等于通用知识问答。
