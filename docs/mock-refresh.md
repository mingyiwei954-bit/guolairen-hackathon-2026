# 双击刷新与 Mock 内容库

- 顶部当前选中的频道连续点击两次（间隔小于 420ms）刷新，首击不重绘导航，兼容触屏轻点。其他频道单击切换。700ms 防连续重复触发，真实请求另有执行中锁。
- 推荐、热榜、关注、故事、知识共 121 条本地示例，其中本轮新增 100 条。每批 12 条，刷新轮换、返回顶部；频道各自保存批次，达到末尾循环，不冒充无限新内容。
- `public/mock-library.js` 包含独立数据与读取层：`mockPool`、`mockItems`、`nextMockBatch`。每条有稳定 ID、内容类型和示例标记；新增内容在 `MOCK_TEXT` 中修改。当前为随版本发布的本地只读内容池，不是后台编辑 CMS。
- 首页详情、故事阅读和转提问均读取当前批次；转提问草稿使用稳定内容 ID，避免刷新后索引重用覆盖另一条草稿。示例点赞标记也使用稳定 ID。
- 过来人刷新继续调用 `/api/feed`，保留方向与阶段；异常保留原内容并提示。没有创建 Mock 真人账号、回答或 AI 证据，没有改变 OAuth 与三问。
- Mock 评论和热度仅作演示，未伪装实时知乎榜单。新虚构热榜不复用不相关的新闻配图。

验收：`node tests/test_mock_library.cjs`，三份 JS 语法检查、`git diff --check`；浏览器快速连续点击验证推荐换批、故事新批次详情一致、过来人真实刷新与回顶。没有调用付费模型。
