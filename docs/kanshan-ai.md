# 回答流末尾的看山 AI 体验

真人回答全部看完后，继续上滑进入唯一的 AI 尾页。标题“看山 AI”，同时注明“DeepSeek 驱动 · 项目体验”，不宣称接入知乎官方看山接口。AI 页单独展示，不写入真人 answers 表，不参与真人点赞排序。

## 一次生成的定义

同一访客 Cookie、同一问题只保留一条记录，SQLite 主键为 `(visitor_id,question_id)`。进入 AI 页时先 GET；只有这次主动滑入或点击生成、且未生成过时才 POST。恢复页面只 GET。不同访客各自一次；清除 Cookie 会建立新访客，当前未实现账号级跨设备额度。

- `GET /api/questions/{id}/kanshan`：只读，状态 not_started / running / completed / failed。
- `POST /api/questions/{id}/kanshan`：忽略客户端自带问题正文，从数据库读取问题及最多4条回答。事务内原子占位，提交后后台线程调用模型，网络等待不持写锁。相同主键重复请求只返回已有状态。
- 本轮严格最多一次模型请求，不自动修复或重试。超时、模型忙、额度错误、格式错误、网络失败均保存明确失败状态；重复POST也不重试。服务重启遗留 running 标记 interrupted。
- 前端每2秒查询运行状态，最多120秒，超时提供只读“查看生成结果”。离开页面停止轮询，已开始的后台任务继续；查询失败不重新 POST。
- 保存输入快照、提示词版本、实际模型、token用量、耗时和结果。错误信息不返回上游原始文本或密钥。

## 与资料三问的关系

独立于带来源的资料三问。这里是依据问题和社区观点给出的通用 AI 思考，未联网核验，不编造来源。输入里的示例标记保留，提示词明确它们不是事实证据。一般输出200–450字，程序校验非空JSON、长度和禁止伪造网址。本页不提供第二次生成入口。
