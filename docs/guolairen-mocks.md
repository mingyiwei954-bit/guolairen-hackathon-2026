# 过来人示例内容与轮换

`fixtures/guolairen_mock.json` 为人工编写的合成示例：90 个不同标题的问题、180 条回答，每个阶段 30 条回答，覆盖 30 种不同提问阶段→回答阶段组合。来源字段明确标为示例，无外部头像或个人资料，不导入资料检索库。

`demo_content.py` 在启动时幂等增量导入；问题和回答均 `sample=1`，前端继续标示“示例”。不会覆盖用户内容或重置赞同。示例 ID 是稳定数据库 ID，可正常进入详情、点赞和参与回答。

`GET /api/feed?mode=older&stage=all` 返回当前批；显式追加 `refresh=1` 切换到下一批。每位访客、个人阶段、方向和筛选分别记录游标，每批最多 12 条示例。单阶段有至少 30 条可供轮换，相邻批不重叠；转完整个有限池后会循环。排序对访客稳定，普通读请求不会随机跳动，原有演示场景优先进入首批。

真人问题、已有真人回答的示例问题继续保留在可匹配的流中，不参加示例轮换。无可用相对阶段时保留空状态，不伪造小学之前或退休之后的阶段。

验证：`python -m unittest discover -s tests -p 'test_demo_content.py'`。覆盖所有个人阶段/方向/筛选、跨批不重叠、普通读稳定、种子幂等、真实内容保留和示例点赞/详情。
