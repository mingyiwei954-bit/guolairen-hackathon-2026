# 周边频道演示壳

目标：在已有知乎风格导航中提供可点击、可滚动的周边频道，让“过来人”处于完整导航语境中。四个顶部频道（推荐、热榜、故事、知识）与底部“看山”使用本地原创示例，核心过来人问答、三问、OAuth 保持真实功能。

2026-09-14 实际浏览 https://www.zhihu.com/ 的推荐信息流和看山展开页，参考标题/摘要/元信息/细分隔的视觉层级；移动端沿用用户提供的知乎截图。未复制真实作者回答、热度排名或实时资料，也没有接入知乎原生客户端组件。

示例页带轻量“频道预览 · 示例内容”提示，内容仅用于前端呈现，不写入真人问答或资料数据库。看山仅为起始界面预览；提示建议与交互不表示真实模型回复。过来人依旧是项目主体验。加号进入过来人提问，不发布到模拟频道。

验收重点：逐个频道切换与滚动；回到过来人保持阶段、方向和浏览位置；看山和首页互返；已登录状态标签保留；正文及标签不横向溢出；切换无需外部模型调用。版本包和数据库先备份，再发布。
