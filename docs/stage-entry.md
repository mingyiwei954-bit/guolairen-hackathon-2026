# 第四行「我是…」阶段入口

入口位于过来人第四行筛选栏右侧，灰字、独立于可横滑的目标阶段标签；所在悬浮层隐藏时，仍沿用原来的 inert 与焦点规则。底部 OAuth 登录入口不变。

点击打开「我的阶段」独立页，六个白底单选行，蓝色文字和勾号表示选择。顶部箭头取消并恢复原浏览状态，「完成」使用已有 POST /api/profile 持久保存当前访客阶段，保持浏览方向，将目标阶段重置为全部，再请求对应内容。不会重写已发布问题或答案。

写入失败保留选择供重试；写入成功但刷新失败明确告知已保存，重试仅请求内容，不重复提交阶段。提交时禁用选择、返回和完成，防止重复触发。

2026-09-14 本地真实联调：大学切工作后，入口为「我是上班族」，听过来人筛选只剩全部/退休；选择初中后取消，仍是上班族；恢复大学成功。输入与选择使用原生 radio，支持键盘焦点。414px 手机容器下筛选栏无横向溢出。JS 语法及 diff 检查通过。
