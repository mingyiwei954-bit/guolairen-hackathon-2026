# 同题回答吸附流

过来人 item 详情现为白底无卡片的一屏一答：顶部问题、背景与阶段筛选，中央为当前回答，底部保留当前阶段、点赞、写回答及资料三问。没有搜索、广告、相关内容推荐。

在同一道问题内上下切换回答，不跨问题乱序跳转。短回答方向滑动即可翻一页，CSS scroll snap 配合触摸/滚轮手势确保落在整屏位置；滚轮惯性锁避免一口气跳多条。长回答正文独立滚动，到边界后再换答案。上下箭头及方向键提供替代操作。当前位置按问题保存稳定 answerId，进入资料面板再返回仍回到原回答；新发表答案继续可定位。ResizeObserver 在尺寸变化后重新对齐页高，离开页面时释放。

空余区提供针对当前文字的资料追问入口：自动带入回答片段，只读取已有三问记录，用户点发送才调用模型。明确这是 AI 依据资料讨论，不代表作者本人；仍按问题共用三问额度。本轮没有新增真人私聊或作者追问接口。

验收：本地第一题3条答案，由1/3切至2/3，滚动555px恰等于单页高度，底部票数随当前答案由36变24；AI输入带入当前雪糕回答，返回仍为2/3。未发布测试问题/答案，未调用模型。node tests/test_answer_deck.cjs 验证滚轮、惯性、长文边界、首尾边界与方向触摸；浏览器实测按钮吸附和AI读取，真机触摸手感仍需用户体验。Mock与刷新回归检查通过。
