# 匿名回答详情

详情保留同题上下吸附回答流，移除阶段筛选与“高赞优先”文案。旧草稿或详情保存的阶段不会隐藏答案，真实问题仍显示实际回答数量。

底栏参考提供的知乎回答页：左侧匿名/写回答，右侧线框赞同、向下三角、收藏、追问与更多图标，无头像。赞同使用现有服务端接口；收藏和“暂时没帮到我”仅存在当前浏览器，操作提示明确范围。气泡进入当前回答关联的资料三问，不伪装为作者回复；更多保留写回答和资料三问入口。

`fixtures/answer_demo_expansion.json` 为人工编写的示例补充。增量初始化仅匹配 sample=1 的已知问题，每题补足3条，不删除现有答案，不向真实问题填充虚构回答。98个初始示例问题均有3条不同回答，示例仍有标识，与资料证据库隔离。

验收：三条答案翻页与边界、旧阶段状态恢复、底栏点赞后保持三角图标、收藏切换、初始化幂等与真实空问题保留。运行 `node tests/test_answer_deck.cjs` 与 `.venv-content/bin/python -m unittest discover -s tests -p test_demo_content.py`。

## 滑动与文字精简更新

统一 Pointer Events 支持手机触摸和桌面按住拖动，短答案上下拖动后吸附到相邻答案；长正文先滚动，抵达边缘后的继续拖动切换。限制滚轮惯性跨多页，独立拖动不受上一手势动画锁影响；横向拖动、取消手势及拖动后的误点击不会翻页或打开追问。保留浏览器缩放手势。

回答信息行仅保留匿名与阶段；移除“关于这条回答”、示例徽标和重复赞同人数，赞同数留在底栏。内容属性仍保存在数据中，可在底栏更多操作内查看。
