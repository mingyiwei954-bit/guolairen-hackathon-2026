# 回答详情与公开身份（已替代旧匿名方案）

问答列表、问题详情与回答展示固定昵称、插画头像和自选阶段。所有新发布内容使用同一套公开显示身份，发布页提前展示昵称。资料库引用继续保留原作者，与生成的演示角色分开。

`public_identity.py` 提供 48 个固定演示角色及 24 个本地 DiceBear Thumbs 头像（CC0）。演示角色按内容 ID 和阶段稳定分配；实际访客以同一浏览器会话拥有稳定的公开身份。API 不暴露内部 owner 或会话令牌，不反查或公开此前的真实身份。当前未做跨设备昵称同步或自定义昵称；清除浏览器会话会获得新身份。

详情连续滚动，圆形返回悬浮于左上角。每次进入先显示「问问看山」入口，点击后才读取或生成 AI 内容。来源词条加大字号，摘录最多 80 字，默认两条，其余折叠。
